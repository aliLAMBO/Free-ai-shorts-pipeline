# Free-ai-shorts-pipeline

A completely free workflow to create 50–70 second vertical animated / story shorts.  
Works on high-end phones and regular laptops. No powerful GPU required.

## What you get
- Ready-to-use prompts
- Clear step-by-step workflow
- List of free tools and their current free limits
- Example script

## Quick Start
1. Open `prompts/script-prompt.md` and replace the topic.
2. Paste it into Gemini (or any free LLM).
3. Follow the steps in `workflow.md`.
4. Edit everything in CapCut.
